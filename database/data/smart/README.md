# Smart content for seeders (shared hosting)

Place these JSON files here so `php artisan db:seed` works without a sibling `smart/` repo:

- projects.json
- rooms.json
- collection.json
- services.json
- articles.json
- press.json
- awards.json
- about.json (optional)

Images still come from `public/assets/` (same paths as `/assets/img/...` in JSON).
